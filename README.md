# 📐 Algoritmo Neural Simples com Matrizes
Estudo de Matemática Aplicada e Álgebra Linear

Este projeto foi desenvolvido com fins educacionais como parte do curso de Matemática e Estatística Aplicada para Machine Learning e Inteligência Artificial, oferecido pela Data Science Academy (DSA). O foco principal do projeto é o entendimento prático da matemática por trás de algoritmos de Machine Learning, com ênfase em multiplicação de matrizes e na implementação manual de um algoritmo simples, porém funcional, construído do zero.

---

## 🎯 Objetivo do Projeto

- Aplicar conceitos de álgebra linear em um contexto computacional
- Implementar manualmente a lógica de um algoritmo neural simples
- Trabalhar com operações matriciais, sem depender de frameworks de ML
- Compreender a estrutura básica de um algoritmo de aprendizado
- Consolidar o aprendizado teórico por meio da prática em Jupyter Notebook

---

## 🧠 Descrição do Algoritmo

O algoritmo implementado neste projeto segue uma abordagem educacional, simulando o funcionamento básico de uma rede neural simples. A implementação foi organizada em uma classe, responsável por:
- Inicializar parâmetros (pesos)
- Executar operações de multiplicação de matrizes
- Realizar iterações de treinamento
- Atualizar os parâmetros com base nos resultados obtidos
- Toda a lógica matemática é explicitamente implementada, permitindo visualizar claramente como os dados fluem pelo algoritmo.

---

## 🧩 Estrutura da Classe

A classe principal do projeto foi criada para encapsular o comportamento do algoritmo, tornando o código mais organizado e reutilizável.
De forma geral, a classe contempla:

- Construtor (__init__)
Responsável por inicializar os parâmetros do modelo, como pesos, taxa de aprendizado e número de iterações.
- Método de propagação direta (forward)
Realiza a multiplicação matricial entre entradas e pesos, representando o processamento do algoritmo.
- Método de treinamento
Executa múltiplas iterações, ajustando os pesos de acordo com os resultados obtidos.

Essa abordagem ajuda a compreender como algoritmos de ML são estruturados internamente, mesmo em versões simplificadas.

## 📓 Jupyter Notebook

O projeto foi desenvolvido inteiramente em um Jupyter Notebook, o que permite:

- Explicações intercaladas com código
- Visualização clara das etapas do algoritmo
- Execução incremental das células
- Testes e validações durante o desenvolvimento
O notebook contém:
- Explicações conceituais em texto (Markdown)
- Implementação passo a passo do algoritmo
- Testes com dados de entrada
- Observações sobre erros comuns e ajustes necessários
Essa estrutura facilita tanto o aprendizado quanto a revisão do conteúdo.
